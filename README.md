# Dialoging

Конвертер диалогов в разметку в духе движка Undertale: пишешь обычный текст,
вставляешь токены-иконки, получаешь готовую строку с управляющими кодами.

- `index.html` — приложение целиком, один файл, без сборки. Открывается двойным кликом.
- `design/icon-set.html` — лист иконок (17 токенов, 2 варианта отрисовки).

## Разметка

| Группа | Токен | Код |
|---|---|---|
| Тайминг | Пауза / Пауза мс / Скорость / Мгновенно | `^2` `{p:250}` `{s:2}` `{instant}` |
| Поток | Строка / Ждать / Закрыть | `&` `/` `%` |
| Стиль | Цвет / Сброс | `\R \G \B \Y \P \O \W` · `\X` |
| Персонаж | Голос / Лицо | `\TS` `\E1` |
| Движение | Тряска / Дрожь букв / Волна / Качание / Глитч | `{shake:2}…{/shake}` и т.д. |
| Звук | Звук | `{snd:hit}` |

Парные токены движения оборачивают выделение. Черновик сохраняется в браузере.
