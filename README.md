# Dialoging

Конвертер диалогов в разметку в духе движка Undertale: пишешь обычный текст,
вставляешь токены-иконки, получаешь готовую строку с управляющими кодами.

- `index.html` — приложение целиком, один файл, без сборки. Открывается двойным кликом.
- `design/icon-set.html` — лист иконок (17 токенов, 2 варианта отрисовки).

## Разметка

| Группа | Токен | Код |
|---|---|---|
| Тайминг | Пауза / Пауза мс / Скорость / Мгновенно | `^2` `{p:250}` `{s:2}` `{instant}` |
| Поток | Строка / Ждать / Закрыть | `&` `/` `%` |
| Стиль | Цвет / Сброс | `\R \G \B \Y \P \O \W` или `{c:#RRGGBB}` · `\X` |
| Персонаж | Голос / Лицо | `\TS` `\E1` |
| Движение | Тряска / Дрожь букв / Волна / Качание / Глитч | `{shake:2}…{/shake}` и т.д. |
| Звук | Звук | `{snd:hit}` |

Парные токены движения оборачивают выделение. Черновик сохраняется в браузере.

## Свои значения

У каждого параметра есть быстрые пресеты и поле свободного ввода — клик по чипу,
поле под пресетами, Enter или OK. Принимается любое значение: `{s:0.25}`,
`{p:3000}`, `{shake:0.5}`, `\TSANS`, `{snd:door_open}`, цвет как `#8ED1FC`.
Десятичная запятая приводится к точке, пробелы обрезаются.

Значение, недопустимое для оригинального Undertale (например `^12` — после `^`
там читается ровно одна цифра), не блокируется: показывается предупреждение,
и повторное OK ставит его как есть.

## Десктопное приложение (Windows)

`desktop/` — нативный редактор диалогов на Rust + egui. Без браузера, без
WebView2 и без .NET: один `.exe`, который просто запускается.

Готовый бинарь — во вкладке **Releases**. Собирается на настоящей Windows
через GitHub Actions (`.github/workflows/desktop.yml`), поэтому ставить
тулчейн, чтобы им пользоваться, не нужно.

Собрать самому:

```
cd desktop
cargo build --release      # бинарь в target/release/
cargo test                 # 28 тестов на логику разметки
```

Под Linux дополнительно нужны `libasound2-dev`, `libxkbcommon-dev`,
`libgl1-mesa-dev`, `libx11-dev`. Скрипт `desktop/devshot.sh` запускает
приложение на виртуальном экране и снимает кадр — им проверялась отрисовка.

Что уже умеет: редактор с чипами внутри текста, все 17 токенов, свободный
ввод значений, пикер цвета со своей палитрой, превью с посимвольной печатью,
пятью эффектами движения и синтезированным звуком печати по голосам.
